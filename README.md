# Applied Computing by Michael Mallari

**[michaelmallari.github.io](https://michaelmallari.github.io/)**

High-performance computing, algorithms, and foundational mathematics, implemented in C++ and Python and GPU-accelerated with Nvidia CUDA.

Each post starts with a question you might actually ask, like "How long until my savings double?" or "How does a search engine find one word so fast?" It answers in plain words first, then gives the exact math, then shows the code in small steps. Every code sample runs, and the output you see on the page comes from running it.

## What you'll find

| Section | What it covers |
|---|---|
| [High-Performance Computing](https://michaelmallari.github.io/high-performance-computing/) | Parallel programming, GPU kernels, memory, and benchmarks across CPUs and GPUs |
| [Algorithms](https://michaelmallari.github.io/algorithms/) | Sorting, searching, graphs, and parallel patterns |
| [Mathematics](https://michaelmallari.github.io/mathematics/) | Algebra, discrete math, geometry, linear algebra, and calculus for computing |

Every post has the same parts:

- a plain-language story with one everyday analogy
- the precise math, with each symbol explained
- code in small parts, with C++ and Python side by side in tabs
- key takeaways, plus a short exercise with a hidden answer

Some posts first appeared on my student web pages in the 1990s. They keep their original dates. They've been rewritten with modern code and newer references, and each one says so under the byline.

## About this repository

This repository holds only the generated website: static HTML, CSS, and images in `docs/`, served by GitHub Pages. The site is built with [Hugo](https://gohugo.io/) and a custom theme. The posts' source and code are kept elsewhere, so pull requests against `docs/` can't be merged.

Spotted a typo, a broken link, or a math or code error in a post? Please [open an issue](https://github.com/michaelmallari/michaelmallari.github.io/issues) with the post's link. Corrections are welcome.
